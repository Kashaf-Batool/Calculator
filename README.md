# Java Swing Calculator

A modern desktop calculator built using **Java Swing** that provides a clean graphical user interface and supports both basic and advanced mathematical operations.

## Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- √ Square Root
- x² Square
- x³ Cube
- Clear (C)
- Backspace (Delete Last Digit)
- Calculation History Display
- Simple and User-Friendly Interface

## Technologies Used

- Java
- Java Swing
- AWT

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Kashaf-Batool/Calculator.git
```

2. Open the project in your preferred Java IDE (VS Code, IntelliJ IDEA, or Eclipse).

3. Compile and run:

```bash
javac Main.java Calculator.java
java Main
```
